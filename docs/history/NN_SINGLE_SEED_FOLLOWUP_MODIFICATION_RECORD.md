# 单种子结果后的神经网络改进方案与修改记录

日期：2026-07-26

## 1. 当前证据

三套 seed42 结果均具有 `evaluation_status.json: COMPLETE`，指标文件哈希匹配，
比较汇总状态为 `COMPLETE`。

### 1.1 置信度

相对于 A0（关闭 MC 置信度），A13（完整 MC 置信度）：

- 平均准确率提高 0.216 个百分点；
- 同一测试集、按 root 家族配对 bootstrap 的 95% 区间为
  `[+0.131, +0.305]` 个百分点；
- Heavy×M、Heavy×K、Med-RD×K、Heavy×C 的 L1 recall 明显改善；
- Small×K 的 L1 recall 下降 1.73 个百分点，但其 bootstrap 区间跨 0，
  尚不能证明这是稳定损害。

因此，“全局关闭置信度”不成立。下一步恢复置信度，只把 Small×K 作为
选择性绕过的待验证单元，不扩展到缺乏证据的其他单元。

### 1.2 三分类分布损失

相对于 A0，A14（关闭三分类分布损失）：

- 平均准确率下降 0.278 个百分点；
- 配对 root bootstrap 95% 区间为 `[-0.374, -0.188]`；
- Med-RD×K、Med-LM×C、Heavy×C 等弱单元显著下降；
- Brier、MC均值交叉熵、ECE与平均精确率均变差。

所以保留 `class_distribution_weight=0.25`。但该损失对各单元作用不一致，
不能继续全局增大；只对弱单元的“精确 L1 行”增加该项，累计 BCE、IPW、
采样和阈值均保持不变。

### 1.3 阈值与表征问题

逐样本概率分析显示：

- Small×K 在 K0 FP≤0.5% 时，A0 可达到的 damage-entry recall 约 28.7%，
  与实际 L1 recall 28.4% 几乎一致。继续降低阈值无法解决问题。
- Small×C、Med-RD×C 也接近 C0 FP≤2.5% 下的当前可达边界。
- Med-RD×M 的 damage-entry recall 可达约 96.7%，但精确 L1 recall 只有
  53.7%，说明主要错误是 L1/L2 分离，而不是 L0/L1 阈值。

因此不降低误报门禁，也不把调阈值当作模型能力提升。

## 2. 已实施修改

### 2.1 选择性置信度

新增配置项：

`data.label_confidence_strength_by_task_munition`

- 4×4矩阵，行顺序 K/M/F/C，列顺序
  Small/Med-LM/Med-RD/Heavy；
- `1` 保留完整 MC 置信度；
- `0` 将该单元置信度恢复为 1，即不降权；
- 中间值可做连续收缩；
- 数值必须位于 `[0,1]`。

该操作只改变损失权重，不改变 MC 概率目标。

### 2.2 弱单元精确 L1 分布损失

新增：

`loss.middle_class_distribution_multiplier`

- 4×4矩阵，任务/弹型顺序同上；
- 只作用于硬标签恰为 L1 的样本；
- 只乘显式三分类分布损失，不乘累计 BCE；
- 默认全 1；候选最大为 2；
- 不启用 focal、pos_weight、重采样或旧 class-1 alpha。

候选矩阵：

```text
K: [2.00, 1.25, 1.50, 1.25]
M: [1.00, 1.00, 2.00, 1.50]
F: [1.00, 1.00, 1.00, 1.00]
C: [1.50, 1.50, 1.25, 1.50]
```

矩阵依据是当前门禁缺口和 A0/A14 的单元级配对结果，并限制最大值为 2，
避免再次形成多套类别平衡机制。

### 2.3 2×2 因子实验

- `A13_with_label_confidence`：完整置信度，无弱单元增强（已有结果）。
- `A15_selective_confidence`：只绕过 Small×K 置信度。
- `A16_weak_cell_middle_loss`：完整置信度，只增加弱单元 L1 分布损失。
- `A17_selective_confidence_weak_cell_loss`：两项同时启用，作为候选基线。

这样可以分别判断两项改动及其交互，不把多项变化混成一次训练。

### 2.4 结果可信度

新增 `abli_exp/analyze_single_seed_predictions.py`：

- 强制三个实验的 sample/root/硬标签逐行一致；
- 输出全部16个“弹型×任务”的准确率、L1 precision/recall/F1；
- 输出精确 L1 概率质量、L0/L1与L1/L2 AUC；
- 输出误报约束下的 damage-entry recall 上限；
- 对同一测试集执行配对 root-cluster bootstrap；
- 明确声明单种子 bootstrap 不能替代多随机种子训练。

运行清单升级为 v2，新增配置 SHA-256、训练/数据/模型/评估源码 SHA-256、
Python解释器和平台信息。比较器同时输出性能门禁通过值和失败项数量。

## 6. 正式执行结果（seed42）

### 6.1 训练候选被否定

所有候选均完成训练、评估、ONNX一致性校验和哈希封存，但都没有超过A13：

| 实验 | 平均准确率 | 相对A13（百分点，95% root-bootstrap CI） | 门禁失败数 | 结论 |
|---|---:|---:|---:|---|
| A13 | 93.1300% | 基准 | 8 | 保留默认基线 |
| A15 | 92.9502% | -0.180 `[-0.274,-0.098]` | 11 | 否定 |
| A16 | 92.8654% | -0.265 `[-0.350,-0.168]` | 11 | 否定 |
| A17 | 93.0019% | -0.128 `[-0.213,-0.050]` | 12 | 否定 |

A15证明仅取消Small×K置信度衰减不能改善该单元，并会通过共享表征损害其他
任务。A16/A17证明宽范围中间类加权会改善部分单元，但其负迁移和总体准确率
代价更大。三项配置不得进入seed43/44，也不得作为部署候选。

### 6.2 发现阈值目标与门禁不一致

原联合阈值搜索优化三分类准确率及两个累计序数头F1，最终门禁检查的却是
精确L1召回。两者并不等价，尤其Med-RD×M有约33.5%的L1被判为L2。

修复内容：

- 阈值schema升级为`v8_exact_l1_floor_constrained`；
- 若精确L1召回目标在验证集可达且不违反误报上限，优先选择满足目标的阈值；
- 若不可达，保留最优安全阈值，绝不为“通过门禁”突破Small×K0或C0误报上限；
- 可配置每单元三分类准确率下降预算；
- 新增验证集专用再校准工具，复用模型时校验模型SHA-256不变，并重新封存阈值
  和manifest；
- 旧A13合同缺少分单元置信度矩阵字段时，只允许按“全1默认矩阵”进行语义迁移；
  非默认矩阵及其他合同差异仍拒绝。

### 6.4 当前可分性证据

A13测试集精确L1错误方向表明：

- Small×K：召回26.64%，其余73.36%全部落到L0；在0.5% L0误报约束下，
  当前概率分数的damage-entry召回上限同为26.64%；
- Small×C、Med-LM×C、Med-RD×C在2.5% L0误报诊断约束下的entry召回上限

因此统一“所有支持数≥100单元精确L1召回≥85%”是严格的研究目标，但对当前

允许部署；后续报告应另外增加“验证集可达性门禁”，不能通过降低阈值伪造通过。

## 12. A26显式三类Softmax序数头

现有累积双Logit只能通过`P(L>=1)-P(L>=2)`间接形成中间等级概率。A26增加
可选的三类Softmax输出，直接学习`P(L0), P(L1), P(L2)`，再严格转换为：

- `P(L>=1)=P(L1)+P(L2)`；
- `P(L>=2)=P(L2)`。

因此外部仍输出两个累积Logit，单调性、结构零、损失、阈值和ONNX部署接口均
不变。A26只改变这一项参数化，13维输入、软标签、MC置信度、损失和45轮预算
均与A13一致。

seed42在第34轮按预注册耐心规则早停，最终选择第24轮。validation结果：

- 平均准确率92.7297%，相对A19下降0.4355个百分点；
- 严格失败项8→9；
- Small×K0 FP为0.4200%，全局C0 FP为2.3049%，安全上限仍通过；
- 8个预注册弱单元排序目标没有一项达到`+0.002`；
- 排序目标平均变化`-0.00947`，其中6项下降超过0.003。

因此`validation_promotion.status=FAIL`、`test_metrics_read=false`，且A26目录
不存在`test_metrics.json`。这一结果否定“仅把累积Logit改成显式三类概率即可
解决当前弱单元”的假设，不允许用测试集补做事后选择。

## 13. 当前验收结论

- 默认平衡方案仍为A13权重+A19的v8阈值校准；
- 它具有稳定的约93.08%平均准确率、良好概率质量和稳定安全误报上限；
